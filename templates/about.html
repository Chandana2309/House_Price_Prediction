About This Application

The House Price Predictor is a Machine Learning web application built using Flask and the California Housing Dataset. Users enter housing features such as income, house age, rooms, population, and location to receive an estimated house price predicted by a trained ML model.

Key Features

  • 🔐 Secure user login & signup system
  • 🤖 ML model trained using Random Forest Regression
  • ⚡ Real-time prediction of house prices
  • 🎨 Clean, modern UI with responsive design

Machine Learning Workflow

  • Dataset: California Housing Dataset
  • Preprocessing: cleaning, scaling, feature selection
  • Model: Random Forest Regressor
  • Pipeline: StandardScaler + RandomForest
  • Model File: model.joblib

Purpose of This Project

This project helps beginners understand real-world ML deployment. It is ideal for academic learning, portfolio building, and showcasing end-to-end machine learning workflow integrated with a modern UI.

Technologies Used

  • Frontend: HTML, CSS, Bootstrap
  • Backend: Python Flask
  • ML Libraries: scikit-learn, pandas, numpy
  • Database: SQLite
  • Model Deployment: Flask + Joblib
